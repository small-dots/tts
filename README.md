# Breeze TTS Studio

本地 AI 声音创作工作台，使用 Vue 3 / Vite / Ant Design Vue / SCSS 与 Node.js / Express。模型服务独立运行，工作台不修改任何模型代码。

开发交接、需求实现状态与关键实现逻辑见 [AGENTS.md](AGENTS.md)。

## 快速开始

需要 Node.js **22 或以上**。在此目录运行：

```bash
npm install
npm run dev
```

打开 **http://127.0.0.1:5173**。此命令同时启动前端（5173）和本地 API（3001）。在「系统设置」填写模型服务根地址，默认 `http://127.0.0.1:7860`。启动你的 Breeze TTS 2 服务后即可生成语音。

可选环境变量：复制 `.env.example` 为 `.env`。`BREEZE_API_URL` 仅作为首次创建设置的默认地址；之后以界面保存的设置为准。`STUDIO_DATA_DIR` 指定元数据目录；`BREEZE_TIMEOUT_MS` 为上游请求最长时间，默认 600000 毫秒。

### 前后端独立启动

```bash
npm run dev:server
npm run dev:client
```

Vite 将 `/api` 代理到 `127.0.0.1:3001`。若修改 `PORT`，同时修改 `vite.config.js` 中的代理地址。

### 生产运行

```bash
npm run build
npm start
```

打开 **http://127.0.0.1:3001**。Express 同时提供构建后的界面与 API。所有服务仅绑定 `127.0.0.1`，定位为单机使用。开发进程与生产进程不要同时占用同一个 API 端口。

## 已实现

- 声音设计、声音克隆、声音指导，各模式独立保存文字草稿，切换不丢失输入。
- 六组中英文声音设计示例、六组声音指导示例，可自由编辑。
- 中文/英文语言选择，光标位置插入 `[笑]`、`[咳嗽]`、`[清嗓子]`、`[叹气]` 或相应英文事件。
- WAV 拖放/文件上传（20 MB 上限）、文件名/大小/时长展示、音频预览、准确文字稿和声音授权校验。
- Web Audio API 分块解码并播放原始 PCM，支持暂停、继续、重播、拖动进度、音量与真实音频波形。
- 正确封装 PCM16 / 24000 Hz / 单声道 WAV，完成后可重播与下载。
- 全服务单任务控制；其他浏览器的并发请求返回 HTTP 409，不绕过模型单并发限制。
- 本地历史记录：时间、模式、文本、参数、参考文件名称、状态、音频；支持搜索、筛选、试听、下载、删除、复用。
- 声音预设：保存参数、命名、应用和删除；参考音频只有明确勾选并确认授权后才持久保存。
- 服务连接检测、默认 CFG / Seed 策略、输出目录、保留记录数量、深浅主题、响应式布局。
- `⌘ / Ctrl + Enter` 生成；输入校验和服务故障提示。

## 模型服务契约

请求 `POST {apiUrl}/v1/audio/speech`，使用 `multipart/form-data`：

| 参数          | 设计   | 克隆     | 指导     |
| ------------- | ------ | -------- | -------- |
| `text`        | 必填   | 必填     | 必填     |
| `instruction` | 必填   | 不传递   | 必填     |
| `cfg_scale`   | 默认 4 | 不传递   | 默认 4   |
| `ref_audio`   | 不传递 | WAV 必填 | WAV 必填 |
| `ref_text`    | 不传递 | 必填     | 必填     |
| `seed`        | 可选   | 可选     | 可选     |

UI 的模式、语言选择、授权状态不会被当成模型参数传递。语言仅用于界面事件和示例，描述与待生成文本应使用相同语言。CFG、seed 的最终有效范围仍需以模型实现为准；工作台 CFG 可选 0.5–20，seed 为 0–2147483647 或留空。

响应应为 **24,000 Hz、单声道、16-bit signed little-endian 原始 PCM**，常用 `Content-Type: application/octet-stream` 或 `audio/pcm`。不将原始响应误当成 WAV。非 PCM 类型、空音频、不完整采样、断流会报错且不会生成可下载的成功记录。

服务检测优先检查 `/openapi.json` 的语音端点，再尝试该端点的 GET（405 可证明路由存在）。界面中的「已连接」表示接口可访问，不代表模型已成功加载；不虚构 GPU 或显存数据。

### 停止与并发语义

停止按钮中断浏览器接收并立即停止播放。由于断开 HTTP 不保证模型停止计算，Node 会继续消费当前上游响应，保持任务锁，直至上游结束或超时。此期间显示上游任务进行中，下一请求返回 409。取消记录不会提供部分 WAV 下载。

## 本地存储

默认目录：

```text
data/
  studio.json        # 设置、历史和自定义预设元数据
  audio/             # 完成的 WAV 音频（可在设置中更改）
  references/        # 仅明确勾选保存的预设参考音频
```

- 普通生成上传保存在请求内存中，历史只记录参考音频名称与文字稿，不保存参考文件；复用这类历史时需重新上传并确认授权。
- 文字草稿、当前主题保存在当前浏览器的 localStorage。文件对象、音频内容与授权勾选状态不写入浏览器草稿。
- 更改输出目录只影响之后的生成。历史仍指向已有音频原路径。
- 调小保留条数会删除超出数量的旧元数据与音频；`全部保留` 表示不自动删除。
- 删除预设会同时删除该预设独立保存的参考音频。
- 请保留整个数据目录和自定义音频输出目录以便备份。不要在多个 Node 实例间共用同一数据目录；支持一个服务被多个浏览器访问。

## 工作台 API

| 接口                                        | 说明                                        |
| ------------------------------------------- | ------------------------------------------- |
| `GET /api/health`                           | 服务探测、当前全局任务状态                  |
| `GET /api/settings` / `PUT /api/settings`   | 读取/保存设置                               |
| `POST /api/speech`                          | 验证、单任务控制、转发 PCM 流并持久保存 WAV |
| `GET /api/history` / `GET /api/history/:id` | 历史列表/详情                               |
| `DELETE /api/history/:id`                   | 删除历史与音频                              |
| `GET /api/audio/:id`                        | 支持浏览器播放的 WAV                        |
| `GET /api/audio/:id/download`               | 下载 WAV                                    |
| `GET /api/presets` / `POST /api/presets`    | 自定义预设读取/保存                         |
| `DELETE /api/presets/:id`                   | 删除预设与其参考文件                        |
| `GET /api/presets/:id/reference`            | 读取明确保存的参考音频                      |

## 验证

```bash
npm test
npm run build
```

测试使用 Node 自带测试框架和真实本地 HTTP 夹具，覆盖 WAV 字节格式、奇数分块、参数校验、模型字段转发、流式首块、并发拒绝、取消后保持锁、故障/空/截断/错误类型响应、磁盘重载、引用音频显式授权、清理和历史删除。

`tests/fixture-server.js` 是独立的手动 UI 校验夹具，输出安静的 **2 秒测试正弦音，不生成语音**。运行 `node tests/fixture-server.js` 后，可临时将模型地址设为 `http://127.0.0.1:7861` 校验完整链路。正常启动不使用该夹具。声音质量、克隆相似度和情绪控制效果需要通过实际模型服务验收。

## V1.0 边界

不包含批量生成、训练、ASR、账号、商业计费与公开部署。模型权重和输出的许可需遵循原项目要求；本工作台面向本地研究、测试及非商业用途。音频格式和接口不匹配时请调整适配层，不要修改模型核心推理逻辑。
